# Student ID Scanner — ওয়েব ভার্সন (ল্যাপটপ কিয়স্ক)

মোবাইল অ্যাপের (Student ID Scanner Cloud) ওয়েব সংস্করণ। একই Firebase ডাটা ব্যবহার করে, তাই **একই Gmail দিয়ে লগইন করলে ফোনের অ্যাপের সব তথ্য এখানেও দেখা যাবে** — ছাত্র, হাজিরা, স্ক্যান হিস্ট্রি সব এক।

## কী করা যাবে

- **কিয়স্ক স্ক্যান — দুই মোড:** **হাজিরা স্ক্যান** (ডিফল্ট): স্ক্যান করলেই হাজিরা লেখা হবে, "ধন্যবাদ আপনার হাজিরা সম্পূর্ণ" দেখিয়ে ৪ সেকেন্ড পর নিজে নিজেই আবার স্ক্যানের জন্য তৈরি হবে — কাউকে থাকতে হবে না। **তথ্য দেখুন:** স্ক্যান করলে শুধু ছাত্রের তথ্য দেখাবে, হাজিরা বা হিস্ট্রি কিছু লেখা হবে না; "আবার স্ক্যান করুন" বোতামে চাপ দিলে আবার স্ক্যান হবে। সাথে লাইভ ঘড়ি আর "আজ কতজন স্ক্যান হয়েছে" কাউন্টার আছে।
- **ছাত্রদের তালিকা:** শ্রেণি অনুযায়ী সাজানো তালিকা, খোঁজা যাবে আইডি/নাম/শ্রেণি/রোল দিয়ে। নামে চাপ দিলে প্রোফাইল আর শনি–শুক্র সাপ্তাহিক হাজিরা দেখা যাবে।
- **স্ক্যান হিস্ট্রি:** আজকের স্ক্যান নতুন থেকে পুরনো ক্রমে।

## যা করা যাবে না (ইচ্ছা করেই)

ওয়েব ভার্সন **শুধু দেখা আর স্ক্যানের জন্য**। এখানে ছাত্র যোগ/বদল/মোছা যাবে না, অ্যাডমিন PIN-এর কাজও নেই — সেসব ফোনের অ্যাপে করতে হবে। নতুন কিছু বানানোও হয় না: প্রোফাইল না থাকলে ডিফল্ট নাম দেখাবে, কোনো ডেমো ছাত্র যোগ হবে না। স্ক্যান করলে শুধু হাজিরা আর হিস্ট্রি লেখা হয়।

## মনে রাখবেন

- **ছবি ল্যাপটপে দেখা যাবে না।** ছবি শুধু যে ফোনে যোগ করা হয়েছে সেই ফোনেই থাকে (ক্লাউড অ্যাপের নিয়ম)। ল্যাপটপে নামের প্রথম অক্ষর দেখাবে।
- ল্যাপটপে **Chrome ব্রাউজার** ব্যবহার করুন, ক্যামেরার অনুমতি দিন, আর সাইটটি **HTTPS** দিয়ে খুলতে হবে (যেমন GitHub Pages)। `file://` দিয়ে খুললে ক্যামেরা চলবে না।

## কীভাবে খুলবেন

1. সাইটের ঠিকানা ব্রাউজারে খুলুন।
2. **"Google দিয়ে লগইন করুন"** বোতামে চাপ দিয়ে ফোনের অ্যাপের একই Gmail বেছে নিন।
3. **"ক্যামেরা চালু করুন"** চাপ দিন, ক্যামেরার অনুমতি দিন।
4. ছাত্র কার্ডটি ক্যামেরার সামনে ধরুন — হাজিরা মোডে স্ক্যান হলে "ধন্যবাদ আপনার হাজিরা সম্পূর্ণ" দেখিয়ে নিজে নিজেই আবার স্ক্যানের জন্য তৈরি হবে; তথ্য মোডে শুধু তথ্য দেখাবে।

## কারিগরি কথা

- কোনো বিল্ড ধাপ নেই — `index.html`, `app.js`, `style.css`, `firebase-config.js` এই চারটি ফাইলই সাইট।
- Firebase JS SDK v10 (compat) আর QR পড়ার জন্য jsQR — দুটোই CDN থেকে আসে।
- Firebase কনফিগ `firebase-config.js`-এ আছে; এটি পাবলিক ওয়েব কনফিগ (অ্যান্ড্রয়েড অ্যাপের মতোই)। আসল সুরক্ষা Firestore-এর নিয়মে — প্রত্যেকে শুধু নিজের UID-এর তথ্য দেখতে পারে।
